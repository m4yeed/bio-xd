## Features

- Text-editor style layout with tabs: `about.md`, `projects.js`, `stack.sh`, `playlist.m3u`, `links.txt`
- Interactive terminal in `stack.sh`
- ASCII bunny animation
- Music player with a playlist, covers and an equalizer
- Minimal black and white look with a custom cursor

## Run locally

1. Click the green **Code** button → **Download ZIP**, then unzip it.
2. Open `index.html` in your browser.

No installation or build step needed.

## Built with

HTML, CSS and vanilla JavaScript.

## Customize

Fork the repo and replace the text, links, covers and songs with your own. Feel free to use it as a base for your own bio page.
